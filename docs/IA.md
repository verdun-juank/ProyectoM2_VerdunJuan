## Registro del uso de IA en el proyecto

Durante el desarrollo se utilizó ChatGPT como herramienta de apoyo para aprender, resolver dudas en especial con SQL 

La IA se utilizó como asistente, mientras que la implementación, revisión y ejecución de las pruebas se realizaron durante el desarrollo del proyecto.

### Principales usos

- Comprender la estructura de una API REST con Node.js y Express.
- Separar las rutas, los servicios y los middlewares.
- Comprender las consultas SQL parametrizadas y la relación entre autores y publicaciones.
- Resolver errores durante la implementación.
- Crear y comprender pruebas automatizadas con Jest y Supertest.

**Organización del código:**

> ¿Cómo puedo separar las rutas de la lógica de negocio utilizando services en mi API de Node.js y Express? Explícame paso a paso y utiliza mi estructura actual.

**Pruebas automatizadas:**

> Quiero agregar pruebas unitarias a mis servicios utilizando Jest y mocks para simular PostgreSQL. Explícame cómo funciona cada parte del código.

**Documentación:**

> ¿Cómo puedo documentar mis endpoints REST utilizando OpenAPI y Swagger UI? Necesito comprender cómo se definen las rutas, los parámetros y las respuestas.

**Resolución de errores:**

> Tengo un problema con la relación entre autores y publicaciones. Ayúdame a identificar si la clave foránea y las consultas SQL están correctamente implementadas.

### Reflexión sobre el uso de IA

La utilización de IA permitió comprender mejor conceptos de backend, resolver errores y avanzar de manera progresiva en la construcción de la API.

Se utilizó principalmente para obtener explicaciones, ejemplos y orientación técnica. Las soluciones propuestas fueron revisadas y probadas antes de incorporarse al proyecto.
